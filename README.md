# Vozes do Espectro — Tecnologia, Educação e Desenvolvimento Profissional

Documentação pedagógica, planos de aula, materiais, projetos e avaliação de resultados do módulo de **Informática e Tecnologia** desenvolvido no Projeto Vozes do Espectro.

**Parceria:** Fundação Eufraten | CPQD
