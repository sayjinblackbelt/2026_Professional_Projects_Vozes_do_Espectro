# Planos de Aula

Esta seção reúne planos representativos das aulas desenvolvidas no percurso.

Os planos registram:

- tema;
- objetivos;
- atividades;
- competências;
- recursos;
- desenvolvimento;
- reflexão e encerramento.

A estrutura facilita a reutilização e adaptação das propostas em novos contextos educacionais.
