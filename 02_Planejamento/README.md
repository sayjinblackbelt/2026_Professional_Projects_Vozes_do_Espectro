# Planejamento do Percurso

Esta seção organiza a lógica de planejamento utilizada no módulo de Tecnologia.

## Elementos

- objetivos de aprendizagem;
- sequência dos conteúdos;
- competências técnicas e comportamentais;
- integração entre teoria e prática;
- preparação de atividades e projetos;
- avaliação e acompanhamento.

## Lógica do percurso

**Planejar → Ensinar → Praticar → Aplicar → Avaliar → Refletir**

O planejamento priorizou progressão gradual e aplicação dos conhecimentos em situações próximas ao contexto profissional.
