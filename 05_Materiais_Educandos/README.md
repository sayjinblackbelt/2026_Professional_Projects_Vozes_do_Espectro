# Materiais dos Educandos

Materiais destinados à realização das atividades práticas.

## Objetivos

- orientar etapas;
- facilitar autonomia;
- organizar entregas;
- apoiar utilização das ferramentas;
- estimular revisão e reflexão.

Os materiais devem ser claros, objetivos e adequados ao nível de autonomia esperado em cada atividade.
