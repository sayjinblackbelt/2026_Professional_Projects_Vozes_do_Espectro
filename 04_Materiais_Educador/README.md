# Materiais do Educador

Recursos utilizados para apoiar a preparação e condução das aulas.

## Exemplos

- roteiros de aula;
- orientações de atividades;
- prompts demonstrativos;
- critérios de avaliação;
- materiais de apoio;
- guias para demonstrações práticas.

Os materiais podem servir como referência para replicação e adaptação pedagógica.
